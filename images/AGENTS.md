# AGENTS.md (images/)

本目录存放文章用的图片。drawio 源图和导出的 PNG 都放在这里，按主题分子目录（如 `images/gevent/`、`images/chatgpt/`）。

## drawio 源图工作流

文章里的示意图优先使用 drawio 制作。**源文件和产物分离**：

- `foo.drawio` —— 纯 XML 源，git 友好，所有编辑都改它；
- `foo.png` —— 由 `make` 渲染出来的纯产物，**不嵌入 XML**，文章引用这个。

> 注意：本目录的 `.png` 不是 `.drawio.png`。我们刻意去掉了 PNG 里嵌入 XML 的能力，PNG 只作为只读产物。所有可视化或文本编辑都通过打开 `.drawio` 源完成。

## 唯一修改路径

1. 编辑 `foo.drawio`：
   - drawio app 打开 `.drawio` 文件，用 GUI 改；
   - 或者用文本编辑器 / ast-grep 直接改 XML（AI 协作常用）。
2. 在 `images/` 目录运行 `make`，重新生成对应 `foo.png`。
3. 提交 `.drawio` 和 `.png` 两份。

**不要试图编辑 `.png`**：drawio app 双击 `.png` 只能把它当背景图导入，不能修改节点。Makefile 也只看 `.drawio` 源，PNG 单独被改下次 make 会被覆盖。

## Makefile

`images/Makefile` 递归扫描子目录里所有 `*.drawio` 源，按需重新生成同名 `*.png`。

```bash
# 在 images/ 目录下：
make            # 渲染所有过期的 .png（增量，源未改动则跳过）
make list       # 列出当前所有源和对应产物
make clean      # 删除所有由 .drawio 生成的 .png（保留源文件）
make gevent/gevent-trace-timeline.png  # 只渲染单张
```

底层命令固定为：

```bash
drawio -x -f png -b 16 --scale 2 -o <out>.png <in>.drawio
```

- `-b 16` 四周留 16px 边距；
- `--scale 2` 2x 像素密度；
- 故意**不加 `-e`**，PNG 不嵌入 XML。

## 新增图片的步骤

1. 在合适的子目录下放 `foo.drawio`（可以从 drawio app 另存为 `.drawio`，或直接写 XML）；
2. 在 `images/` 目录运行 `make`；
3. 文章中按相对路径引用，例如：

   ```markdown
   ![说明文字](images/gevent/foo.png)
   ```

## 命名约定

- 主题子目录：小写、连字符，如 `gevent`、`chatgpt`、`dubbo`；
- 文件名：能独立看懂，避免与文章日期强绑定，如 `gevent-trace-timeline.drawio` 而不是 `2026-05-08-figure-1.drawio`；
- 一张图一份源：不要把多张图塞进同一个 drawio 文件的多个 page，diff 和增量构建会变难。

## 绘图风格基线

新图请遵循下面的约束，避免每张图各搞一套样式。`images/_styles.drawio` 是一份可视化模板，drawio app 里打开它能直接复制粘贴节点和箭头到新图，免去手敲样式串。

### 配色（限制 6 色，按语义选）

颜色分两类用途，**不要混用**：

- **语义编码**（红/橙/绿）：颜色本身承载含义。红 = 危险/异常/失败；橙 = 警告/注意；绿 = 成功（本图集暂不用）。一旦某张图里红色 = 危险，**所有图里红色都只能是危险**，不能挪作"第一类、第一代"这种分类编码。
- **分类编码**（区分类别、不带评价）：不要用红/橙做分类，用**单色相明度递进**（浅蓝 -> 中蓝 -> 深蓝）或**蓝+灰**组合。表示"旧 vs 新"时，旧的用炭灰（legacy 感、不带"差"的暗示），新的用主蓝。

| 色 | 十六进制 | 用途 |
|---|---|---|
| 正文/边框 | `#1F2937` | 默认描边、正文字 |
| 辅助灰 | `#6B7280` | 注释、辅助线、时间轴 |
| 浅灰背景 | `#F3F4F6` | 泳道底色、区块背景 |
| 旧/弱化 | `#E5E7EB` fill / `#6B7280` stroke | 被取代的旧方案、legacy；不要用红色 |
| 强调蓝 | `#1F6FEB` | 主线流程 / 主角对象 / 当下最佳方案 |
| 强调橙 | `#B45309` | 对照路径 / 被穿插内容（语义偏中性，非警告） |
| 警示红 | `#B91C1C` | 异常 / 错误路径 / 危险窗口（**仅限语义编码，不做分类**） |

节点填充用浅色（`#DBEAFE` 配主蓝 / `#BFDBFE` 配深主蓝 / `#FEF3C7` 配橙 / `#FEE2E2` 配红 / `#E5E7EB` 配灰 / `#F3F4F6` 配辅助灰），描边用上面的深色。**单图最多用 3 种主色**（含灰阶）。蓝/橙是色盲友好对照，不要换成红绿。

### 形状与线条

| 元素 | 约束 |
|---|---|
| 节点形状 | 圆角矩形，`arcSize=6`（实际半径约 2-3px，避免产品宣传感）。对于尺寸偏大的容器框，建议显式 `arcSize=5;absoluteArcSize=1` 把圆角钉死成 5px 绝对像素，否则 drawio 默认按相对百分比算会显得圆角过大 |
| 描边宽度 | 1.5px（drawio 默认 1px 偏细，PNG 缩略发糊） |
| 节点填充 | 配色表里的浅色变体 |
| 主流箭头 | 实线，`#1F2937`，1.5px，classic 细箭头 |
| 异步/切换箭头 | 虚线，`#6B7280`，1.5px |
| 异常箭头 | 实线，`#B91C1C`，1.5px |
| 箭头继色 | 同一条流上的箭头跟起点节点颜色一致 |

### 字体

```text
fontFamily="Noto Sans CJK SC,Helvetica"   # 中英文混排，显式指定避免别人机器上发糊
fontFamily="Courier New"                  # 代码 / 标识符 / API 名
```

### 字号

| 用途 | 字号 |
|---|---|
| 标题 / 泳道名 | 14pt bold |
| 节点正文 | 12pt（默认） |
| 事件流 / 表内文字 | 11pt |
| 注释 / 旁标 | 10pt italic，颜色 `#6B7280` |

**不要为了塞下而压到 9pt**。塞不下 = 删元素，不是缩字号。

### 布局

- 节点之间最小间距：
  - 有箭头相连（实线/虚线）：**≥ 30px**，否则箭头被两节点边夹住，几乎不可见
  - 无箭头（仅视觉分组、表格行）：≥ 10px
  - 无关元素之间：≥ 40px
- 泳道高度 ≥ 60px；
- 所有节点要么左对齐要么居中对齐，不要"几乎对齐"；
- 垂直流程图（每个节点占一整行、自上而下用箭头连）特别要注意：默认让每个节点占 60-80px 行高 + 30px 间距，不要为了"挤进一屏"压成 50px 行高 + 5px 间距 -- 箭头会消失；
- 画完图后扫一眼：5 秒能不能看懂这张图想说什么？不能就删元素。

### 反模式（禁止）

- 阴影、渐变、3D 效果——缩略后糊，毫无信息价值
- 大圆角（默认 `arcSize=20`+ 或绝对 8px 以上）——像产品宣传图，技术图不需要
- 4 种以上颜色 / 彩虹配色——读者记不住色 → 含义的映射
- 9pt 以下字号——别人截图后不可读
- 红绿对比——10% 男性色盲分不清，用蓝橙

### 速查清单（画完图前对照）

- [ ] 主色 ≤ 3 种（含灰阶）
- [ ] 红/橙仅用作语义（危险/警告），分类用蓝色明度梯度或蓝+灰
- [ ] 描边 1.5px、`arcSize=6`（大容器框用 `arcSize=5;absoluteArcSize=1`）
- [ ] 中文字体 `Noto Sans CJK SC,Helvetica`，代码 `Courier New`
- [ ] 字号 ≥ 10pt
- [ ] 有箭头相连的节点间距 ≥ 30px（垂直流程图特别检查）
- [ ] 异步关系用虚线，异常路径用红色
- [ ] 节点对齐到 10px 网格
- [ ] 5 秒能扫懂这张图想说什么

## 其他图片格式

非 drawio 图（截图 PNG、JPG、GIF、外部 SVG）正常存放即可，不需要 Makefile 参与。这些图与 drawio 渲染出的 `.png` 通过有无同名 `.drawio` 源来区分：有同名源的 `.png` 是产物，没有的则是手工管理的素材。
